# לוח סבב סטודנטים

לוח של שבועיים לסבב הסטודנטים באורתופדיה, כאתר רגיל: כל מי שיש לו את הקישור רואה את הלוח, ורק מי שמחזיק במפתח העריכה יכול לשנות אותו.

- **צפייה:** פותחים את הקישור לאתר. לא צריך חשבון.
- **עריכה:** לוחצים על "עריכה" ומדביקים את מפתח העריכה (GitHub fine-grained token עם הרשאת Contents: Read and write למאגר הזה). המפתח נשמר רק בדפדפן שבו הדבקתם אותו.
- **הנתונים:** כל הלוח נמצא בקובץ `schedule.json`. כל שמירה מהאתר נשמרת כגרסה חדשה של הקובץ, כך שאפשר לראות היסטוריה ולשחזר גרסה קודמת.

---

Two-week student rotation schedule, served with GitHub Pages. Anyone with the link can view it. Editing needs a fine-grained token with Contents read/write on this repository; the token stays in the editor's browser. The schedule lives in `schedule.json`, and each save from the site is a commit to it.
